Brutal Doom 64: Veteran of Hell is an expanded and modernised fork of Brutal Doom 64 that transforms Doom 64 into a larger, tougher, and more customisable experience. It preserves Doom 64's atmosphere and visual style while adding new monsters, weapons, gameplay systems, difficulty options, player classes, and extensive customisation. Originally developed as a bug-fixing update for Sargeant Mark IV's Brutal Doom 64 v2, the project grew into a complete standalone fork with years of additional content and gameplay improvements.
